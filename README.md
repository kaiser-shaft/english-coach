# English Coach for Software Engineers

Персональный AI-методист и спарринг-партнер по английскому языку для разработчиков.
Цель: переход с уровня **A2+** к уверенному **B1+** с фокусом на Production (деловая и техническая переписка, PR-ревью, баг-репорты, архитектурные обсуждения, созвоны и снятие языкового барьера).

---

## 📁 Структура репозитория

| Файл / Каталог | Назначение |
|---|---|
| [`AGENTS.md`](AGENTS.md) | Системный промпт, правила поведения AI-коуча и методология ведения сессий. |
| [`ROADMAP.md`](ROADMAP.md) | Дорожная карта обучения: 5 модулей по 4 недели с практическими контрольными гейтами. |

| [`JOURNAL.md`](JOURNAL.md) | Лог прошедших занятий, фиксация успехов, домашек и заметок по барьеру. |
| [`.agents/workflows/`](.agents/workflows/) | Автоматизированные сценарии: `start-session.md` и `end-session.md`. |

## 🚀 Как работать с коучем

Каждое занятие длится около **30 минут**:
1. **Старт занятия**: вызовите воркфлоу `/start-session` (или напишите «Начнем занятие»). Коуч прочитает текущее состояние из `STATE.md`, последние записи `JOURNAL.md` и начнет с короткого разогрева.
2. **Основная часть**: разбор шаблона недели из `FRAMES.md` и отработка на ваших реальных рабочих задачах и кейсах.
3. **Разбор**: наглядная таблица типичных ошибок и рекомендаций по их естественному исправлению.
4. **Завершение**: вызовите воркфлоу `/end-session`. Коуч зафиксирует итоги в `JOURNAL.md` и актуализирует `STATE.md`.
