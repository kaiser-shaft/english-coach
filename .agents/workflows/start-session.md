---
description: Начать занятие по английскому
---

1. Прочитай STATE.md.
2. Прочитай последние 3 записи в конце JOURNAL.md (если файл пуст — это первое занятие).
3. В ROADMAP.md найди раздел текущей недели из STATE.md и прочитай только его.
4. В FRAMES.md найди шаблоны, соответствующие этой неделе (по теме, не читай всё).
5. Коротко (2–3 строки, по-русски) поприветствуй, назови тему сегодняшнего занятия. Не пересказывай файлы.
6. Начни с разогрева: задай ПЕРВЫЙ вопрос (по-английски) и жди ответа.
